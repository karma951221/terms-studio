# 용어사전

> 상태: 초안 · 최종수정: 2026-10-07
>
> 한 개념에 한 이름. 여기 없는 말은 기획 문서에서 쓰지 않는다. 정본 정의는 [[00_시작/도메인모델]].

## 실체

| 용어 | 정의 | 아닌 것 |
|---|---|---|
| **담보** | 재사용되는 보장 단위의 마스터. 문면 1벌과 세부보장 트리를 소유 | 상품에 실린 것(→ 상품담보) |
| **세부보장** | 담보 안에서 지급사유가 갈라지는 단위 (예: 수술비 담보의 1종수술~7종수술) | 세목의 종·형 |
| **급부** | 보험금이 지급되는 최소 단위. 조건식·파생이 최종적으로 붙는 자리 | — |
| **상품** | 약관 책자 1권의 단위. 개정판은 별개 상품 | — |
| **상품담보** | 담보를 상품에 탑재한 것. 같은 담보를 한 상품에 여러 번 탑재 가능 | 담보의 복사본 (구조는 공유) |
| **탑재** | 담보 → 상품담보 생성. 이 순간 마스터 값이 스냅샷으로 복사됨 | 참조 (값은 이후 독립) |
| **기본계약** | 상품모델링 「기본계약」 섹션의 상품담보. 주계약에서 수가 약관 모양을 정한다 — 하나면 대치(케이스 1), 둘 이상이면 절 형태의 블록(케이스 2) ([[기능/조립산출/결정/ADR-0021-기본계약수-보통약관구조]] · [[기능/조립산출/결정/ADR-0082-제1절-자동판정-준용하기-독립특약]]). 지금 구현은 정확히 1개 | — |
| **주계약 / 독립특약** | 상품특성 계약형태의 두 값. 주계약은 기본계약을 둔다. 독립특약은 기본계약을 두지 않고(지정하면 오류) 문면이 있는 탑재 상품담보가 블록이 된다(블록은 미구현) — 단독 가입 불가, 주계약에 부가돼 가입 | — |
| **블록** (보장조항 블록) | 절 형태 약관의 제2절 보장조항에 실리는 보장 단위 — 케이스 2는 기본계약 상품담보, 케이스 3은 문면이 있는 탑재 상품담보 전부(사용자 결정의 「종속특약」). 담보 문면 통째, 블록마다 조 번호 재시작, 머리 = 블록 번호 + 제목(케이스 3 「{상품담보명} 특별약관」 · 케이스 2 상품담보명). 조립이 생성. 특약 그룹을 보지 않는다(미구현) | 마스터에 있는 구조 · 특약 그룹 |
| **케이스 1 · 2 · 3** | 약관 조립 모양 셋 — 계약형태 + 블록 수가 정한다. 1 = 주계약 · 기본계약 하나(대치 형태 — 절 없음) · 2 = 주계약 · 기본계약 2+ · 3 = 독립특약(블록 1 이상, 0이면 오류). 2 · 3은 절 형태 ([[기능/조립산출/결정/ADR-0082-제1절-자동판정-준용하기-독립특약]] — 2 · 3 은 미구현) | 기본계약 수만으로 가르는 것 |
| **절 형태** | 제1절 일반조항(보통약관 템플릿을 판정한 조 목록 — 관 · 조 연번) / 제2절 보장조항(블록 나열)으로 나뉜 약관. 케이스 2 · 3. 블록이 하나여도 절을 나눈다(미구현) | 템플릿의 절 구조(템플릿은 평평한 조 목록) |
| **블록 머리 · 블록 순서** | 블록 머리 = 제2절에서 블록 앞에 서는 블록 번호 + 제목. 블록 순서 = 제2절의 블록 차례 — 공통 · 합침 항의 차례(첫 블록 기준)도 이것을 따르고, 판정 결과와는 무관하다. 번호 꼴 · 순서의 저장 방식은 확정 전 ([[기능/조립산출/조립산출]] §5, 미구현) | 특약 그룹 안 자동 정렬 |
| **복합 블록** | 블록 안에 하위 보장이 준-조 「1.(…)」로 든 담보. 이번 범위 밖 — 탑재하면 경고, 판정 분모에서 뺀다(미구현). 후속 기획 필요 | — |
| **세목** | 한 상품 안에서 계약이 고르는 배타적 선택지 체계 (종·형 등) | 담보명의 「종」(수술 분류 등급) |
| **세목유형** | 세목 선택지의 종류. 유형 하나 = 구조체 하나. 납입면제유형 · 무저해지유형 · 계약전환형 · 영위업종적용형 · 납입형태 | 고지유형 (→ 상품 레벨 구분자) |
| **종형 번호** | 세목 선택지의 문면 번호 표기 (제N종/제N형). 선택 속성 — 없는 선택지도 있다 | 유형 그 자체 |
| **상품세목** | 명시 등록된 종·형 유효 조합. 카테시안이 아니다 | — |

## 값

| 용어 | 정의 | 아닌 것 |
|---|---|---|
| **구분자** | 값의 정의 단위. 문면이 묻는 **개념**으로 딴다. 부착 레벨 5개: 상품·세목·담보·세부보장·급부 | 운영 형태·세목 (값이 채워지는 경로일 뿐) |
| **구조체** | 구분자의 타입. 폼 하나 = 구조체 타입 구분자 하나. 필드는 구조체가 직접 소유, 중첩 금지 | 구분자들의 묶음 (필드는 독립 구분자가 아님) |
| **필드** | 구조체 안의 항목. 타입: string·number·boolean·date·enum·list\<enum\>·list\<T\> | 독립 채번 단위 |
| **직접 (값)** | 상품모델링 화면에서 사람이 정하는 값 | — |
| **파생 (값)** | 식으로 계산되는 값. 식은 데이터로 저장 — 코드 금지. 연산: any·all·sum·count(distinct)·exist·not exist. 범위 = 부착점의 하위 트리 | 개발 요청으로 코드에 심는 로직 |
| **const 구분자** | 값이 마스터 정의에 사는 구분자 (예: 평균공시이율). 템플릿이 참조. MVP 는 string 만 | 상품이 정하는 값 |
| **상품담보명 규칙** (구: 작명 메타) | 상품담보명을 짓는 카탈로그 전역 칩 규칙 한 줄. 재료 = 담보명 · 담보속성 값의 상품담보명 표기 · 상품특성 간편심사유형 · 건강고지유형(상품특성은 미구현) ([[기능/담보속성/담보속성]] §3.4) | — |

## 조문

> **2026-09-16** — 「문면」은 구 용어다. 옛 문서 · 기존 ADR 제목의 「문면」은 「조문」으로 읽는다 ([[공통/화면/디자인원칙]] §11.2 · [[공통/화면/화면단어]]).

| 용어 | 정의 | 아닌 것 |
|---|---|---|
| **조문** (구: 문면) | 약관의 문장. 관>조>항>호>목. **항상 마스터 소유** — 상품은 담보약관 문장을 고칠 수 없고, 보통약관은 조 사본으로만 고친다 | — |
| **보통약관 템플릿** (구: 보통약관 마스터 · 문면) | 보통약관 조문 한 벌. 여러 벌 존재, 상품이 선택. 상품별 변주는 옵션 오버라이드 · 조 노출 토글 · 조 사본 셋([[기능/상품/상품]] §3.6). 기본계약 대치 · 제1절 판정은 상품 구성(기본계약 · 블록)이 정한다 | 상품이 소유한 사본 |
| **담보약관 템플릿** (구: 문면) | 담보가 소유한 담보약관 조문 한 벌. 조건 분기로 상품담보마다 다른 문서가 찍혀 나온다 | 상품담보별 사본 |
| **조연결** | 담보약관의 조 → 대응 보통약관의 **같은 자리(대응)** 조. 쓰임은 상품이 정한다 — 케이스 1은 대치, 절 형태는 제1절 판정의 재료(블록 하나면 위임), 특약은 준용 · 생략 판단의 짝 | 내용이 비슷한 인접 조 |
| **준용 규칙** | 특약 ↔ 보통약관: 조연결된 조를 항 단위 리터럴 비교해 생략 / 준용(준용 문장 + 남은 항) / 통째로 자동 판정. 옵션은 block 참조의 「비교 제외」 하나 ([[기능/조립산출/조립산출]]) | 기존 시스템 3종 옵션의 복제 · 사람이 관계 유형 선언 · 제1절 판정(블록끼리) |
| **조 사본** | 상품이 보통약관 템플릿 조를 조 단위로 고친 것 — 고친 조만 상품 것 ([[기능/상품/결정/ADR-0079-보통약관-조사본-템플릿추종-변경표시]]) | 함수조항 복제 · 문서 복제 |
| **사본 잠금 · 회색 사본** | 이 상품의 블록 · 기본계약이 조연결한 템플릿 조는 조 사본을 만들 수 없다(잠금). 잠기기 전에 있던 사본은 지우지 않고 쓰지 않는다(회색) — 연결이 풀리면 다시 쓰인다 ([[기능/조립산출/결정/ADR-0082-제1절-자동판정-준용하기-독립특약]], 미구현) | 사본 삭제 |
| **판정 대상 조 · 판정** | 절 형태에서 이 상품의 블록이 하나라도 조연결한 템플릿 조와, 시스템이 그 조에 내리는 결과 — 마스터(연결 0) · 특칙 · 공통 · 위임 · 공통항 분리 · 전체항 합침 ([[기능/조립산출/결정/ADR-0082-제1절-자동판정-준용하기-독립특약]], 미구현) | 템플릿 저작자가 쓰는 위임 조 |
| **특칙** | 일부 블록만 조연결한 조의 판정 — 제1절은 마스터 그대로, 연결한 블록만 자기 조를 그대로 싣는다. 준용하기 옵션과 무관(미구현) | 특별약관 |
| **마스터 문구** | 판정 대상 조의 템플릿(또는 이 상품의 쓰이는 사본) 문구. 연결 0(판정 「마스터」) · 일부 연결(특칙)일 때 제1절에 찍힌다 — 연결될 조도 템플릿 저작자는 마스터 문구를 쓴다 | 블록 조의 글 · 위임 문구 |
| **판정 기록 · 판정 배지** | 판정 기록 = 조립이 템플릿 조마다 남기는 판정 근거(연결 k/N · 연결한 · 안 한 블록 · 옵션 · 결과 · 블록별 처리 · 사유 · 대치 내역). 판정 배지 = 그 결과를 보통약관 탭 목차 · 미리보기 판정 패널에 보이는 표시(「특칙 k/N」 · 「위임 N/N」 …, 마스터는 없음). 둘 다 저장하지 않는 계산값 ([[기능/조립산출/조립산출]] §3.9 · [[기능/상품/상품]] §3.12, 미구현) | 저장하는 판정 결과 · 특약 조 판정 배지(생략 · 준용 · 통째) |
| **준용하기 옵션** | 보통약관 템플릿 조의 옵션 — 없음(기본) · 공통항 모으기 · 전체항 모으기. 모든 블록이 그 조에 조연결했을 때만 작동 ([[기능/문면/문면]] §3.10, 미구현) | 함수조항 옵션 · 준용 규칙 |
| **공통 항 · 전용 항** | 공통항 모으기에서 연결한 모든 블록 조에 「같다」로 든 항(제1절로 오른다) / 그 밖의 블록 항(블록 조에 준용 문구 ① 뒤 ②부터) (미구현) | — |
| **위임 문구 · 준용 문구** | 조립이 만드는 두 문장 — 위임 문구 「제N조(조 제목)는 제2절 보장조항에서 정합니다.」(제1절, N = 그 조 자신의 번호) · 준용 문구 「제1절 일반조항 제N조(조 제목) 및 아래의 각 항을 따릅니다.」(공통항 분리 때 블록 조 ①) (미구현) | 준용규정 조 · 준용 규칙의 준용 문장 |
| **준용규정** (조) | 담보약관 끝의 「… 보통약관을 따릅니다」류 조. 작성자가 담보약관에 손으로 쓴 것이 정본이고(자동 생성은 사용자 후속 기획), 없으면 조립이 최소형 한 조를 붙인다 ([[기능/조립산출/조립산출]] §3.5) | 준용 규칙(판정) · 준용 문구(시스템 문장) |
| **「같다」** (제1절 판정) | 블록 항끼리 같은 함수조항을 같은 옵션 · 인자로 쓴 것. 일반 글 항은 글자가 같아도 다르다. 항 단위 ([[기능/함수조항/함수조항]] §3.8, 미구현) | 준용 규칙의 리터럴 비교 |
| **위치 호칭** | 제1절 · 문서 전체를 가리키는 참조의 접두를 출력 위치가 정하는 렌더 상수 — 블록(블록 하나 포함)이 제1절 조를 가리키면 「제1절 일반조항 제N조」, 블록의 문서 전체 참조는 「제1절 일반조항」, 케이스 1 특약은 「보통약관」 ([[기능/조립산출/조립산출]] §3.10, 절 형태는 미구현) | 출력 위치로 문구를 가르는 분기(작성_위치) |
| **블록 지정 참조** | 상품 조 사본 안에서만 쓰는 조 참조 범위 — 이 상품의 블록 전체 또는 블록 조(대상 = 상품담보) ([[기능/문면/문면]] §3.5, 미구현) | 템플릿 · 담보약관의 조 참조 |
| **조연결 현황** | 상품 보통약관 탭에서 여는 표 — 판정 대상 템플릿 조 × 블록의 연결 여부. 일부 연결 경고와 함께 조연결 누락을 사람이 가린다 ([[기능/상품/상품]] §3.12, 미구현) | 저장하는 데이터(계산값) |
| **조건 분기** | 값에 따라 조·항·문장(인라인 포함)이 갈라지는 것. if/elif/else. 참조: 상품 레벨 + 담보 레벨 구분자 | — |
| **치환** | 문면의 구멍에 값을 찍는 것. const 참조 + 종별 문구(종형명) 등 최소 범위 — 이름류는 본문에서 안 부름 | 슬롯 남용 (모든 값을 구멍으로) |
| **공용조항** | 담보약관들이 공통으로 가져다 쓰는 문구 템플릿 (예: 특별약관의 소멸, 준용규정) | 완전 동일 문구만 (변형 존재) |
| **별표** | 독립 마스터. 책자가 참조한 것을 모아 마지막에 수록, 나열 순서 = 본문 번호 | 특정 문서의 부속물 |
| **함수조항** (목표 모델, 미구현) | 공용조항의 목표 모델 — 인자 → 내부 변수 → 본문(조건 · switch · 옵션 · 글). 인자 0개 = 고정 문장 ([[기능/함수조항/함수조항]] §3.7) | 공용조항과 나란히 선 둘째 종류 |
| **정적 마스터** | 참조를 품지 않는 고정 내용의 메뉴 — 별표(간접참조, [[기능/별표/별표]]) · 박스(직접참조, [[기능/박스/박스]]) | 함수조항 유형 |
| **납입면제종** | 납입면제 세목 선택지 가운데 적용여부 = 예 인 것 — 사유 묶음(E0001)을 고른다 ([[기능/상품/상품]] §3.9) | 「납입면제형」(무저해지 축의 「형」과 겹침) |
| **문서트리** | 조립의 중간 산출물 — 번호·치환·조건이 전부 해소된 순수 데이터. 스냅샷 검증 대상 | 최종 출력(.docx 등) |
