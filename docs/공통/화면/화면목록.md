# 화면목록

> 상태: 초안 · 최종수정: 2026-09-27

실물 화면(`src/app` 의 `page.tsx`) 하나하나가 어느 문서에서 정의되는지의 표. 화면의 구성 · 상태 · 유저액션은 **담당 기능 문서 §4** 가 정본이다.
공통 규칙은 [[공통/화면/디자인원칙]] · 라벨은 [[공통/화면/화면단어]] · 지금 모습의 그림은 [[공통/화면/와이어프레임]](2026-09-16 기준 — 어긋나면 기능 문서가 이긴다).

레이아웃 유형(L1 조회 · L2 수정 · L3 저작)과 경로 제목 줄 규칙은 디자인원칙 §2 · §1.7 — L1 에는 경로가 없고, 상세(L2 · L3)는 `조회 › 상세` 경로가 곧 제목 줄이다.

## 공통 화면

기능에 속하지 않는 화면. 정의가 짧아 여기 직접 적는다.

| 화면 | route | 코드 | 구성 · 동작 | 근거 |
|---|---|---|---|---|
| 로그인 | `/login` | [page](../../../src/app/login/page.tsx) · [actions](../../../src/app/login/actions.ts) | 사용자 목록에서 하나를 누르면 세션이 열린다 — 비밀번호 없음(MVP). 역할 배지(관리자 · 편집자). 이미 로그인돼 있으면 `/` 로. 사용자가 없으면 시드 관리자를 만든다 | [[공통/화면/결정/ADR-0019-모드폐지-역할권한]] |
| 홈 | `/` | [page](../../../src/app/(app)/page.tsx) | 로그인 뒤 첫 화면. 메뉴를 작업 단계 네 열 + 화살표(기본정보 → 담보 설계 → 약관 조문 → 상품)로 놓고, 점검(관계정보)은 아래 띠. 카드는 이름 + 한 줄 설명만 — 개수 · 경고 없음. 첫 열 「기본정보」는 카드 셋(열거형 → 폼 → 구분자). 경로(제목 줄) 없음 | [[공통/화면/디자인원칙]] §11.2 (내비 작업 단계 묶음) |
| 내비 (모든 `(app)` 화면의 왼쪽) | — | [layout](../../../src/app/(app)/layout.tsx) · [menu.ts](../../../src/app/_lib/menu.ts) · [NavShell](../../../src/app/_components/NavShell.tsx) · [NavLink](../../../src/app/_components/NavLink.tsx) | 홈과 같은 구성(`menu.ts` 한 곳)을 단계 제목 아래 항목으로. 제목 `term-studio` = 홈 링크. 36px 레일로 접기(쿠키 `ts-nav`, 레일에는 펼치기 · 홈 아이콘만). 현재 위치는 `aria-current` — 경로 접두로 판정(`/enums/E0001` → 「열거형」, `/master/waiver` → 「폼」). 아래에 현재 사용자 · 역할 · 로그아웃. 세션이 없으면 `/login` 으로 | [[공통/화면/디자인원칙]] §11.2 · §1.3 |

내비 항목 순서(`menu.ts`): **기본정보** 열거형 · 폼 · 구분자 (참조 순서 — 폼 필드가 열거형을, 구분자 식이 폼 필드를 읽는다) → **담보 설계** 담보 · 담보속성 → **약관 조문** 공용조항 · 보통약관 템플릿 · 담보약관 템플릿 · 별표 → **상품** 상품 → **점검** 관계정보.
