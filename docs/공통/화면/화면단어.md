# 화면 단어 — 라벨 사전

> 상태: 초안 · 최종수정: 2026-09-30 (함수조항 둘레 · 정적 마스터 · 납입면제종 — 미구현)
>
> [[공통/화면/디자인원칙]] §2 L2 「화면 단어」의 실물 사전. 화면에 글자를 적기 전에 여기서 고른다.

## 규칙

1. **같은 것을 가리키면 어디서나 같은 라벨.** 목록 컬럼 · 생성 폼 · 상세 필드 · 확인 팝업 · 빈 상태 문구가 전부 한 말을 쓴다.
2. **다른 것을 가리키면 다른 라벨.** 비슷해 보인다고 같은 말을 돌려쓰지 않는다 (「유형」이 넷을 가리키던 것이 2026-09-09 의 사고였다).
3. **라벨은 `src/app/_lib/labels.ts` 한 곳을 통과한다.** 화면에 문자열을 직접 적으면 다음에 갈라진다.
4. 개발 용어(`scalar` · `struct` · `enum` · 「실체」)는 코드 · 문서에만. 화면에는 안 나온다.
5. **라벨을 바꿀 때 치환 범위는 화면 · 라벨 맵 · 용어사전이다.** 코드 식별자(`document` 등) · URL(`/documents`) · ADR 제목과 파일명은 그대로 두고, 문서 본문은 손댈 때마다 고친다 — 왜: 일괄 치환은 파일명 · 위키링크를 깨고 문맥 따라 다른 말이 맞는 곳을 놓친다.
6. **내부 문서 번호(`ADR-0065` · `§3.7` · `기능/담보 §3.4`)는 화면에 적지 않는다.** 라벨 · 설명 · 안내 · 오류 문구 · 시드 데이터의 설명(구분자 · 폼) 모두 — 근거는 코드 주석에 둔다. 번호를 빼도 문장만으로 뜻이 통하게 쓴다 — 왜: 편집자는 문서를 보지 않으니 번호는 소음이고, 번호가 흡수 · 번복되면 화면이 낡은 번호를 들고 남는다.

## 실체의 이름 칸

**한 실체당 이름 라벨은 하나다.** 그 실체의 목록 컬럼 · 생성 폼 · 상세 필드가 전부 같은 말을 쓴다.
「표시명」은 코드와 짝지어 부르는 **도메인 용어**([[공통/기술/결정/ADR-0005-코드-표시명-이중체계]])라 화면에는 쓰지 않는다.

| 실체 | 화면 라벨 | 지금 섞여 있는 말 |
|---|---|---|
| 구분자 | **구분자명** | 목록 컬럼이 「표시명」 |
| 폼 | **폼 이름** | 목록 · 편집 · 생성 전부 「표시명」 |
| 열거형변수 | **열거형변수 이름** | 전부 「표시명」 |
| 공용조항 | **공용조항명** | 목록 · 생성 「표시명」 |
| 별표 | **별표 이름** | 목록 · 생성 「이름」 (실체가 안 붙어 있다) |
| 담보 | **담보명** | — |
| 상품 | **상품명** | — |
| 담보속성 | **담보속성명** | 「표시명」 |
| 보통약관 템플릿 (구: 문면 · 보통약관 마스터) | **보통약관 템플릿** | 「문면」 「보통약관 마스터」 → 2026-09-16 정리 |
| 담보약관 템플릿 (구: 문면) | **담보약관 템플릿** | 「문면」 → 2026-09-16 정리 |

> 「-명」이 어색한 실체(폼 · 열거형변수 · 별표)만 「<실체> 이름」으로 띄어 쓴다.

## 분류를 부르는 말 — 「유형」 · 「타입」

| 라벨 | 무엇 | 쓰는 자리 |
|---|---|---|
| **유형** | 실체의 분류 | 구분자 유형(일반 · 상수 · 파생) · 공용조항 유형(문구 · 항 · 박스 — 목표 모델 함수조항은 문구 · 항 · 호 · 목, 미구현) · 담보속성 유형 |
| **타입** | **값의 형** (`FieldType`) | 문자열 · 숫자 · 참거짓 · 목록값 |

- 「종류」는 화면에서 쓰지 않는다 → 담보속성의 「종류」는 **유형**으로.
- 실체 분류와 값의 형이 **한 화면에 같이 나오는 경우가 있다**(새 구분자: 유형 + 타입). 그래서 둘을 섞으면 안 된다.

## 열거형변수 둘레 — 「목록값」과 「열거형변수」는 다른 것이다

가장 많이 갈렸던 자리다. **하나는 타입 이름, 하나는 실체 이름이다.**

| 라벨 | 무엇 | 예 |
|---|---|---|
| **목록값** | 값의 **타입** — 「정해진 목록에서 고르는 값」 | 타입: 문자열 · 숫자 · 참거짓 · **목록값** |
| **열거형변수** | 그 목록의 **정의(실체)** — 코드 `E0001` 을 갖는다 | 열거형변수: 납입면제사유 |
| **list 타입** | 목록값에서 **여러 개**를 고르는가 | 체크박스 |

- 「선택지」는 화면에서 쓰지 않는다 → **열거형변수**로. (내비 하위탭 · 폼 목록 컬럼 · enum 화면 제목 · 「선택지 고르기」 전부)
- 도메인 `list<enum>` 의 표시는 **「목록값(복수)」**.

## 함수조항 둘레 — 미구현

2026-09-30 결정([[기능/공용조항/결정/ADR-0076-공용조항-함수조항-일원화-인자연결]] · [[기능/문면/결정/ADR-0077-블록반복-세목선택지-열거목록-반복참조]]). 함수조항 둘레는 화면에 아직 없다 — 메뉴 「공용조항」을 「함수조항」으로 바꾸는 시점은 [[기능/공용조항/공용조항]] §5. 바꿀 때 아래 말을 쓴다.
정적 마스터(별표 · 박스)는 **구현** — 내비 그룹 「정적 마스터」와 박스 화면이 이 말을 쓴다([[기능/박스/박스]] §4).

| 라벨 | 무엇 | 쓰지 않는 말 |
|---|---|---|
| **함수조항** | 인자 → 내부 변수 → 본문을 가진 조항 — 인자 0개가 지금의 공용조항. 메뉴 · 경로 · 실체 이름 칸(「함수조항명」) | 「공용조항」(목표 모델 이후) |
| **인자** | 함수조항 정의의 입력 선언(이름 · 타입 · 기본 연결) | 「파라미터」(표기가 흔들린다) · 「입력」(입력항목과 겹침) · 「틀」 · 「서식」(템플릿과 겹침) |
| **인자 연결** | 넣는 자리에서 인자마다 구분자 · 반복의 현재 원소 · 상수를 대는 것 | 「바인딩」 |
| **인자 기본 연결** | 인자 선언에 적어 둔, 넣을 때 저절로 걸리는 구분자 | — |
| **내부 변수** | 인자를 가공한 이름(사유합치기 · 있음 · 거르기 …) | 「파생」(구분자 유형과 겹침) |
| **옵션** | 함수조항 안에서 정의한 선택지 문구 — 넣는 자리에서 사람이 고른다 | — |
| **값별 분기** (가칭 — 와이어프레임에서 확정) | switch 블록 — 목록값 하나의 값마다 칸 | 「switch」 · 「스위치」(개발 용어) |
| **칸** | 값별 분기의 한 자리(값 여러 개) | 「케이스」 |
| **문구 없음** | 값별 분기에서 아무것도 내지 않는 칸을 명시한 것 | 「기본값」 · 「default」(없는 장치) |
| **정적 마스터** | 내비 그룹 — 하위 별표 · 박스, 참조를 품지 않는 고정 내용 (구현) | — |
| **별표** | 정적 마스터 › 본문이 가리키기만 하고 약관 끝에 실리는 것(간접참조) | — |
| **박스** | 정적 마스터 › 놓인 자리에 내용이 그대로 들어가는 것(직접참조). 이름 칸은 「박스 이름」, 툴바 「박스」 (구현) | 「박스 공용조항」(2026-09-30 없어짐 — 박스는 공용조항이 아니다) |
| **납입면제종** | 납입면제 세목(`waiver`) 선택지 가운데 적용여부 = 예 인 것 | 「납입면제형」 · 「형」(무저해지 축의 「형」과 겹침) |
| **납입면제종마다** | 납입면제종 위의 블록 반복 이름 | 「형마다」 |
| **현재 종 · 현재 사유** | 반복 안에서 읽는 현재 원소 | 「n번째 형」(서수 — 폐지) |

## 열어 둔 것

- 없음. 좌측 내비의 「유형」(열거형변수 · 폼)이 구분자 「유형」과 부딪히던 문제(Q-E)는 2026-09-27 메뉴 「유형」을 걷고 내비 그룹 「기본정보」 아래 메뉴 「열거형」 · 「폼」 · 「구분자」를 따로 세우면서 사라졌다 ([[기능/열거형/열거형]] §6.2).

## 받아들인 겹침

- **「기본정보」** — 내비 그룹 제목 · 홈 첫 열 제목(그 아래 메뉴 열거형 · 폼 · 구분자, [[공통/화면/화면목록]])과 상품 상세의 탭(상품명 · 세목, [[기능/상품/상품]])이 같은 말이다. 그룹 제목은 누르는 메뉴가 아니라 묶음 이름이고, 둘 다 「그 뒤 작업의 바탕이 되는 기본 입력」이라 뜻이 어긋나지 않으며, 한 화면 안에서 같은 자리에 겹치지 않는다(그룹 제목은 내비 · 홈, 탭은 상품 상세 안). 2026-09-27 사용자 결정으로 둘 다 유지한다 — 상품 탭 이름을 바꾸지 않는다.
