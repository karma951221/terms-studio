# ADR-0005 — 코드(불변) + 표시명(가변) 이중 체계

> 상태: 채택 · 날짜: 2026-08-30

## 맥락

참조가 경로(`보험금지급.면책여부`)인데, 경로가 화면 이름 그대로면 이름 변경이 식·조건·문면을
전부 깨뜨린다. 이름 변경 금지는 「잘못 지은 이름을 못 고침 → 새로 채번」으로 중복 채번 문제와
결이 닿는다.

## 결정

**모든 식별 단위(구분자·구조체 필드·enum 값)에 코드+표시명 이중 체계를 공통 적용.**
코드(불변)가 저장·참조의 정본(`cov_pay.exempt`), 표시명(가변)은 화면 전용.
편집기가 표시명 ↔ 코드 변환. 표시명 변경은 언제든 자유.

## 버린 대안

- **이름 = 코드 + 변경 시 일괄 치환** — 치환 누락 = 조용한 파손. 사용처 추적이 완벽해야만 성립.
- **이름 = 코드 + 사용 중 변경 금지** — 이름 개선 불가 → 재채번 유도 → 중복 채번 재발 경로.

## 이유

enum 값에 이미 「코드 불변 + 표시명 가변」을 확정했었다 — 같은 규칙의 확장이라 일관적.
terms-lab 도 같은 결론(식은 ID 기반 AST, 사람은 이름 칩)이었다.
