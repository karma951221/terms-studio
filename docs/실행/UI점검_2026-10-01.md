# UI 점검 — 2026-10-01

> 상태: 초안 · 최종수정: 2026-10-01

만들어진 화면을 브라우저로 보면서 사용자가 짚은 것을 고친 날의 요약이다. 결정의 자세한 이유는 각 기능 문서 §3 · §6.2 와 커밋 메시지에 있다 — 여기에는 핵심과 남은 일만 적는다.

- **검증** — `npx vitest run` 178파일 · 2,221건 통과, `tsc` · `eslint` · `docs:links` 0건. **E2E 는 선택자만 고치고 돌리지 않았다** — 다음에 한 번 돌려 확인해야 한다.
- **개발 방식** — 이날 작업은 구현 뒤 테스트 보강이었다. 남은 일 중 로직이 있는 것은 **TDD**(실패 테스트 먼저)로 한다.
- **DB** — 새 열거형(E0005 고지유형 · E0006 간편심사구분 · E0007 계약형태)과 바뀐 값 목록(E0003 · E0004)은 시드 데이터다. 기존 로컬 DB 는 데이터 디렉토리를 지우고 `npm run db:seed` 로 다시 만든다(마이그레이션 0022 는 옛 뜻의 간편심사유형 · 건강고지유형 값 행만 지운다).
