# 관계정보

> 상태: 초안 · 최종수정: 2026-09-27

## 1. 한 줄

**무엇이 무엇을 참조하는지**를 한 곳에서 보는 점검 도구다 — 조회 대상 하나의 정방향 · 역방향 참조와 이웃 그래프, 그리고 전체의 고아 · 순환 · 깨진 참조.
작성자 · 모델러가 구분자 · 공용조항 · 별표 같은 공유 정의를 **바꾸기 직전에** 「이걸 건드리면 어디까지 번지나」를 확인할 때 쓴다. 밑바탕의 참조 그래프는 다른 화면들의 사용처 · 영향 목록도 같이 쓴다.

## 3. 규칙

### 3.1 참조 그래프

- **참조는 그래프다.** 노드 = 실체, 간선 = 「무엇이(from) 무엇을(to) 어떤 형태로(via) 읽는가」 + 좌표. 대상이 선언되지 않은 간선이 **깨진 참조**다(삭제 뒤 남은 오류 상태).
- 노드 16종 — 구분자 · 입력항목(마스터 필드) · 열거형변수 · 그 값 · 공용조항 · 옵션 · 선택지 · 문서 · 조 · 별표 · 담보 노드(담보 · 세부보장 · 급부) · 담보속성 · 유효값 · 상품 · 상품담보 · 기타 실체.
- 간선 15종을 세 묶음으로 본다.

| 묶음 | 형태 |
|---|---|
| 본문 참조 (값을 읽는다) | 조건식 · 치환 슬롯 · 파생식(구분자 → 필드) |
| 구조 결합 | 노드 한정자(`D@노드`) · 공용조항 참조 · 옵션 선택 · 옵션 오버라이드 · 조 참조 · 조연결 · 별표 참조 · 대응 보통약관 · 담보약관 연결 |
| 참조가 아닌 관계 | 타입 · 탑재 · 담보속성 조합 |

- **포함 관계**(조 ⊂ 문서 · 옵션 ⊂ 공용조항 · 값 ⊂ 열거형변수 · 급부 ⊂ 세부보장 ⊂ 담보)는 간선이 아니라 노드의 부모다. 어떤 실체의 사용처는 그 하위 전부의 사용처를 합친 것이다.
- 조 참조는 대상이 항 · 호 · 목이어도 **속한 조**로 올려 잇는다. 공용조항의 조 참조는 늘 보통약관 마스터를 가리킨다.
- **고아** = 어디서도 참조되지 않는 구분자 · 공용조항 · 별표. 타입 · 탑재 같은 비참조 관계는 참조로 치지 않는다.
- **순환** = 어떤 간선이든 닫힌 경로.
- 표시는 **표시명으로** 부른다 — 「일반상해사망 특별약관 › 제2조(보험금의 감액지급)」. 불변 키(`nodeKey`)는 tooltip 에만. 대상이 삭제됐으면 상위 이름 아래 「…(없음)」, 아무것도 모르면 코드 · id. ([[기능/조립산출/조립산출]] §3.4)

### 3.2 다른 기능이 쓰는 질의

| 질의 | 쓰는 곳 |

| 옵션 오버라이드 사용처 | 관계정보 뷰 · 공용조항 옵션 역조회 ([[기능/공용조항/공용조항]] §3.2) |

### 3.3 그래프 뷰

- **이웃 그래프만 그린다** — 조회 대상을 가운데 둔 1 ~ 3홉. 전체 지도는 만들지 않는다.
- **상한 노드 300 · 간선 600.** 넘으면 **그리지 않는다** — 일부만 그린 그림은 거짓 안심을 준다.
- **배치는 결정적 동심원** — 링 k = k홉, 링 안은 (모양 순 → 키 사전순)으로 균등 각도, 12시에서 시작. 같은 대상을 다시 열면 늘 같은 그림. 노드를 손으로 옮기지 않는다.
  — 왜: 목적이 「바꾸기 직전 확인」이라 어제 본 그림과 오늘 본 그림이 같아야 한다. 대가로 간선 교차는 줄이지 않는다 — 필터와 깊이로 줄인다.
- **서버가 좌표까지 계산한 인라인 SVG** — 새 의존성 없음. 클라이언트는 줌 · 팬 · 호버 강조만, JS 가 없어도 그림과 노드 링크는 산다.
- **종류는 모양 + 테두리 색** — 원(정의류) · 사각(문면류) · 마름모(모델링류)가 1차, `--ts-graph-*` 흙빛이 2차. 색만으로 구별되는 것은 없다. `mark` 는 조회 대상에만, `error` 는 깨진 참조에만 쓰고, 그래프 색은 이 화면 밖으로 새지 않는다.
- **간선은 선 스타일 셋** — 본문 참조 실선 · 구조 결합 파선 · 비참조 점선. 같은 쌍 · 같은 묶음 간선은 한 선으로 묶고 「×N」. 깨진 간선은 `error` 색, 도착 노드는 `error` 점선 + 「(없음)」.
- **포함 관계는 화살표 없는 가는 선** — 그림에 이미 있는 가장 가까운 조상과 잇는다. 홉을 만들지 않는다.
  — 왜: 참조 간선만 그리면 「문서 ↔ 그 문서의 조」가 끊겨 조 노드가 뜬다. 노드를 부모로 뭉치는 변환층은 두지 않는다.
- 문제 개수에는 늘 분모 — 그래프의 노드 · 간선 수는 **필터 적용 전 전체**가 분모다.

## 4. 화면

### 4.1 `/relations` — 관계정보

좌측 메뉴 「점검」 그룹. 상세 화면에서 넘어올 때는 `?kind=&code=&id=` 를 물고 온다(공용조항 상세의 사용처 모달 「관계정보에서 보기 →」).

**구성** (위에서 아래로)

| 자리 | 내용 |
|---|---|
| 제목 줄 | 「관계정보」 |
| 규모 한 줄 | 「참조 노드 N개 중 고아 M · 참조 E건 중 깨짐 B · 순환 C」 + 분모 설명(고아 분모 = 구분자 · 공용조항 · 별표, 깨짐 분모 = 참조 수) |
| 조회 대상 | 유형(select) · 코드 · id · 레벨 · 필드 코드 · 값 코드 → `조회`. 유형마다 필요한 칸이 다르다(예: 공용조항 옵션 = 코드 + 필드 코드) |
| 이웃 그래프 | 조회 대상이 있을 때만. 「노드 n / 전체 · 간선 n / 전체」, 조작 줄, SVG 그림판 |
| 조회 결과 | 대상 이름(삭제됐으면 「— 삭제된 대상, 참조만 남았다」) → 정방향(이것이 참조하는 것) → 역방향(이것을 참조하는 것) → 옵션 오버라이드 사용처 → 깨진 정방향 참조(있을 때만, 「n / 정방향 수」). 줄마다 이름 · 형태 · 원천 좌표 |
| 전체 무결성 | 고아 `n / 후보` · 순환 `n / 참조 수`(경로 「A → B → A」) · 깨진 참조 `n / 참조 수`(「from → to (형태)」) |

**상태**

| 상황 | 화면 |
|---|---|
| 조회 대상 없음 | 그래프 · 조회 결과 없이 규모 · 조회 폼 · 전체 무결성만 |
| 유형만 고르고 필요한 값이 빔 | 오류 배너 「조회에 필요한 값이 비어 있다 — …」 |
| 이웃 0건 | 가운데 노드 하나 + 「연결된 것이 없다」 |
| 상한 초과 | 그림 대신 「이웃이 노드 N개 · 간선 M건이다 — 깊이를 줄이거나 종류를 걸러라」 + 「깊이 k로 낮춰 보기」 링크 |
| 삭제된 대상 | 가운데 노드를 `error` 점선으로, 참조 목록은 그대로 |

**유저액션**

| 누르면 | 결과 |
|---|---|
| `조회` | GET — URL 이 바뀌고 서버가 다시 그린다 |
| 깊이 1 · 2 · 3 / 방향(양방향 · 역방향만 · 정방향만) / 유형 체크 / 형태 묶음(본문 참조 · 구조 결합 · 타입 · 탑재 · 조합) / 포함 관계 → `적용` | GET 폼 — `depth · dir · kinds · vias · containment` 가 URL 에 남아 링크 공유 · 뒤로가기가 산다. 기본: 깊이 1 · 양방향 · 유형 전부 · 비참조 관계 끔 · 포함 관계 켬. 잘못 고친 URL 값은 기본값으로 돌아간다 |
| 노드 클릭 | 그 노드가 새 조회 대상 (`<a>` 링크) |
| 노드 호버 | 붙은 간선 · 상대 노드만 진하게, 나머지 흐리게 + 전체 경로 tooltip |
| 간선 호버 | 형태 이름 + 좌표 tooltip |
| 휠 / 드래그 / `맞춤` | 줌 / 팬 / 원복 (`viewBox` 만 바뀐다) |

그림은 읽기 전용이다 — 그림 위에서 편집하지 않는다.

## 5. 미결

- 이력일자 기준 시점 조회 — 판본([[공통/기술/결정/ADR-0026-이력개정-이력일자-작업본확정]], MVP 이후)이 생기면 기준일을 그래프 적재에 넘긴다. 지금은 작업본 한 시점.
- 「구조 결합」 형태 묶음 체크에 노드 한정자(`nodeQualifier`)가 빠져 있다 — 기본값에는 들어 있지만 `적용`을 한 번 누르면 빠진다. 묶음에 넣을지 따로 둘지.
- 상세 화면들의 「관계정보 →」 진입은 지금 공용조항 하나뿐이다 — 구분자 · 별표 · 담보에도 둘지.
- 그래프를 요청마다 DB 전체에서 만든다 — 규모가 커지면(다중산출 204 상품) 캐시 · 부분 적재를 볼지.
