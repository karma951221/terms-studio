# 폼 입력 시나리오

> 상태: 초안 · 최종수정: 2026-09-01
> 관련 기획: [[기능/구분자/구분자]] · [[기능/담보/담보]] · [[공통/기술/결정/ADR-0004-null없음-미입력상태]]

## 시나리오 1 — 기본값 프리필: 저장 전에는 미입력
**전제**: 구조체 「보험금지급」의 `지급률` 필드에 기본값 100 지정. 담보 「일반상해사망」에 부착, 값 미저장 상태.
**흐름**:
1. 모델링 화면에서 폼 열기 → 지급률 100 이 프리필로 미리 채워져 보인다.
2. 저장하지 않고 화면을 나간다 → 저장소의 값 자리는 여전히 미입력. 완결성 조회에 미입력으로 집계된다.
3. 다시 폼을 열어 프리필을 확인하고 저장 → 그때 비로소 명시 값 100.
**기대 결과**: 기본값이 저장소로 자동 유입되는 경로가 없다 — 저장소의 모든 값에 「사람이 한 번은 보고 저장했다」가 보장된다.
**경계·오류**: 미입력 상태로 이 값을 참조하는 평가·조립 → 오류 + 좌표 보고 (예: 「상품담보 X 의 보험금지급.지급률 미입력 — 제3조 분기 평가 불능」).

## 시나리오 2 — 미입력 상태로 중간 저장
**전제**: 담보 「수술비」의 폼 — 필드 여러 개 중 일부만 값이 정해진 상태.
**흐름**:
1. 필드 일부만 입력하고 저장 → 허용. 나머지 필드는 미입력 상태로 남는다.
2. 이 담보를 상품에 탑재 → 스냅샷이 미입력 상태도 그대로 복사한다.
3. 이후 상품모델링에서 나머지 필드를 채운다.
**기대 결과**: 중간 저장은 언제나 허용 — null 값은 어디에도 생기지 않고, 미입력은 값이 아니라 상태다.
**경계·오류**: 평가가 미입력을 false/0 으로 슬쩍 취급하는 일 없음 — 명시적 오류 + 좌표. 에디터 사전평가에서 미입력 분기는 톤다운이 아니라 「미결」 표시.

> `list<T>`(표 입력) 시나리오는 없다 — **2026-09-01 MVP 타입에서 제외** ([[00_시작/범위]]).
> 입력의 소비처(표 출력)가 동적표와 함께 MVP 밖이라, 동적표 기획 때 함께 재도입한다.

## 시나리오 3 — 완결성 조회: 부착된 것만 대상 · 실행 기반
**전제**: 선택적 노출(무조건 노출 해제) 구분자 「수술관련 값」 — 담보 「수술비」에만 + 버튼으로 부착. 무조건 노출 구분자 「갱신여부」 — 전 담보 노출. 담보 「일반상해사망」에는 수술 전용 구분자 미부착.
**흐름**:
1. 일반상해사망 상품담보의 완결성 조회 실행 → 부착된 구분자(갱신여부 등)의 미입력만 「미입력 N건」으로 집계.
2. 수술비 상품담보의 완결성 조회 → 「수술관련 값」의 미입력이 함께 잡힌다.
**기대 결과**: 수술비 전용 값이 일반상해사망의 미입력 경고로 뜨는 오염이 구조적으로 없다.
**경계·오류**: 미입력이 남은 채 조립 실행 → 부분 조립 + 오류 마커 + 좌표 목록, 「완성본 아님」.

**조회 단위 (2026-09-01 확정)** — 완결성 조회는 목록 대조가 아니라 **실행 기반**이다 (ADR-0016 「밟은 자리만」과 같은 결):
- **담보 마스터 화면**: 그 담보가 탑재된 상품담보들을 기준으로 **실제 타는 분기**를 평가해,
  실행 경로가 읽는데 미입력인 **담보 레벨 구분자**를 보여준다. 탑재된 곳이 없으면 누락도 없다.
- **상품 마스터 화면**: **상품 레벨 구분자** 누락을 **보통약관과 각 상품담보별로** 판별해 보여준다.
- 화면 배치는 [[기능/마스터/마스터]] 몫.
