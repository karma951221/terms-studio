# ADR-0065 — `table` 필드 타입 · 급부 시드 폼(감액 · 면책) · 레벨별 시드 구분자 — 감액 표는 폼 값이다

## 맥락

「감액이 있으면 최초지급금액표(동적 표)를 보인다」 같은 조건식을 담보 약관에서 쓰려면, 급부별 감액 · 면책 정보가 **식이 읽을 수 있는 값**이어야 한다.
감액 · 면책의 입력 UI([[기능/담보/담보]] §3.4 · §3.6)는 급부 카드의 「특성 카드」로 정해졌지만 그 값이 **어디에 사는지**(도메인 붙박이 자리 vs 마스터 폼 값)는 닫지 않았고,
ADR-0042 는 「감액 구간은 급부 아래 구조라 `list<T>` 가 필요 없다」고 했다.

2026-09-16 기획에서 두 길을 비교했다 —
② **붙박이 특성**: 도메인 코드가 감액 · 면책 구조를 알고 식에 `급부.감액.있음` 같은 전용 참조를 낸다. 뜻(마지막 구간 끝 = 기간, 표 열림 = 있음)을 코드가 알아 동적 표 · 피커가 편하다. 대신 특성이 늘 때마다 코드를 고친다.
③ **유저 정의 폼**: 감액 · 면책을 급부 레벨 마스터 폼으로 두고 식은 `폼키.필드키` 로 읽는다. 특성이 늘어도 관리자가 폼을 하나 더 만들면 끝. 대신 표(구간 목록) 타입이 폼 시스템에 필요하고 동적 표 엔진은 「어느 폼의 어느 필드가 구간이냐」를 알아야 한다.

사용자 결정: **③** — 「내가 감액면책만 말했지만 앞으로 더 많은 필드가 늘어날 가능성이 높다」. 이어서 「엔진이 뜻을 아는 법」은 시스템 시드 폼(A)으로.

## 결정

| # | 결정 | 내용 |
|---|---|---|
| 1 | **필드 타입 `table`** | `FieldType` 에 `{ kind: "table"; columns: { key, label, type }[] }` 를 더한다. 열 타입은 스칼라 다섯 — `number` · `percent`(0~100 정수) · `period`(개월 정수 — 입력 `3M`/`1Y`, 표시 `3개월`/`1년`) · `boolean` · `string`. 값은 `{ [열키]: 스칼라 }[]`. 특성 표 부품(첫 행 머리글 · 엑셀 붙여넣기 · 행/열 삭제 · 힌트/오류 — [[기능/담보/담보]] §3.4)이 **`table` 필드의 입력 UI** 가 되고, 열별 파서는 열 타입에 붙는다 |
| 2 | **급부 시드 폼 둘** | 급부 레벨 · 시스템 소유. **`reduction` 감액** — `periods: table{ end: period, rate: percent }` · `after_rate: percent`(선택 · 빈칸 = 100) · `new_only: boolean`(기본 켬). **`exemption` 면책** — `months: period` · `age15_only: boolean`(기본 끔) · `new_only: boolean`(기본 켬). 마이그레이션으로 시드 |
| 3 | **시스템 폼 잠금** | `MasterForm.system` · `MasterField.system` 표식. 시스템 폼은 키 · 레벨 · 시스템 필드의 **삭제 · 타입 변경 불가**, **필드 추가 · 라벨 수정 허용**. 관리자가 만드는 폼은 지금 규칙 그대로 |
| 4 | **「있음」 = 값 입력됨** | 급부 카드에 `reduction` 폼을 열지 않음 = 감액 없음([[기능/담보/담보]] §3.4). 열고 `periods` 를 비움 = 저장 거부. 별도 「감액 여부」 필드 없음. 식에서 「감액 있음」은 새 개념이 아니라 `exist(reduction.periods)` |
| 5 | **투영 구분자는 관리자가 만든다 (시드 없음)** | 필드는 구분자로만 문면에 나온다(ADR-0036). 감액 · 면책을 읽는 문면이 생기면 관리자가 투영(`감액여부 = exist(reduction.periods)` · `면책여부 = exist(exemption.months)` · `면책기간 = exemption.months` …)과 세부보장 · 담보 집계(`any(급부.감액여부)`)를 만든다. 시드에는 두지 않는다 — 2026-09-28 개정: 알파Plus 원문이 하나도 읽지 않아 쓰이지 않는 정의가 카탈로그 · 조건 변수 목록을 채웠다. `감액기간 = max(reduction.periods.end)` 는 **B 단계**(표 열 투영 · `max/min` 집계가 그때 들어온다) |
| 6 | **면책 입력은 기간 + 토글** | 입력 UI 초안의 `조건 \| 기간` 표를 버린다. 실물은 「기간만」과 「15세 이상이면 기간」 둘뿐 — 기간 칸 + 「15세 이상만 적용」 토글 |
| 7 | **상품 덮어쓰기는 공짜** | 폼 값이므로 ADR-0002 스냅샷 · 급부 레벨 값 저장소를 그대로 탄다. 붙박이 자리를 따로 파지 않는다 |
| 8 | **동적 표 엔진의 창구** | 엔진은 `reduction.periods` · `reduction.after_rate` 를 **코드로** 읽는다(시스템 폼이라 키가 불변). ADR-0042 §3 「덮는 급부 구간」 조회의 원천이 이 값이다 |

## 이유

- **폼이면 특성이 늘어도 코드가 안 는다.** 사용자가 밝힌 전제 — 감액 · 면책은 시작일 뿐이다. 붙박이는 둘째 특성부터 매번 참조 종류 · 피커 · 검사기를 고친다.
- **시드 폼이면 뜻은 여전히 시스템이 안다.** ③의 약점(엔진이 필드를 못 찾음)은 「손대면 안 되는 폼」이 되는 것인데, 시드 + 잠금이 그것을 **규칙으로** 만든다. 역할 태그 체계를 새로 배우게 하지 않는다.
- **`table` 하나로 감액 표가 폼 값이 된다.** 감액 구간은 「행 = 구간」인 표다. 폼 시스템에 표 타입이 있으면 특성 카드 부품이 곧 표 필드 입력 UI 라 부품이 둘로 갈리지 않는다.
- **투영 구분자로 ADR-0036 을 지킨다.** 문면은 여전히 구분자만 본다(투영은 필요할 때 관리자가 만든다 — 결정 5). 「급부 감액여부」는 구분자이고, 세부보장 · 담보 레벨의 「감액여부」는 그 구분자를 `any` 로 묶은 구분자다 — 레벨별 집계는 구분자 정의([[기능/구분자/구분자]] §3.2 구분자 → 구분자 참조)로 이미 표현된다.
- **면책은 표가 아니다.** 실물 두 케이스는 기간 하나 + 나이 조건 하나로 끝난다. 표 + 조건식 열(`x>=15`)은 두 케이스를 위해 식 파서를 입력 UI 에 들이는 과잉이었다.

## 버린 대안

- **② 붙박이 특성 참조**(`급부.감액.있음`) — 특성이 늘면 코드가 는다. ③이 포함하지 못하는 이점(뜻을 앎)은 시드 폼이 대신한다.
- **전부 유저 정의 + 역할 태그**(B) — 필드에 「감액구간」 역할을 붙여 엔진이 찾는 안. 역할 체계를 하나 더 배우고, 지금 역할이 필요한 건 감액 하나뿐이라 과하다.
- **전부 유저 정의 + 코드 약속**(C) — 엔진이 `reduction.periods` 문자열을 기대만 하고 잠그지 않음. 이름을 바꾸면 동적 표가 조용히 깨진다.
- **`list<enum>` 을 늘려 구간을 표현** — 구간은 열이 둘(기간 · 지급률)이라 enum 목록으로 안 된다.
- **면책 `조건 \| 기간` 표 유지**(입력 UI 초안) — 위 「면책은 표가 아니다」.
- **마스터 필드를 문면에 직접 노출** — ADR-0066 §버린 대안. 이 ADR 의 시드 구분자가 그 필요를 없앤다.

## 결과와 감수하는 비용

- **ADR-0042 「`list<T>` 불필요」 번복** — 감액 구간은 급부 아래 붙박이 구조가 아니라 **`table` 폼 값**이다. ADR-0042 §3 의 조회(경계 합집합 · 덮는 급부 구간)와 §4 의 붙박이 구분자(셀 글자)는 원천만 바뀌고 그대로다.
- **ADR-0037 「`list<T>` MVP 제외」 개정** — 일반 `list<T>` 는 여전히 없고, **`table`(스칼라 열의 행 목록)만** MVP 에 들어온다.
- **입력 UI([[기능/담보/담보]] §3.4)가 이 결정을 따른다** — 특성 카드 부품 = `table` 필드 입력 UI(표 + 토글 + 힌트) · 면책 = 기간 + 토글.
- **`Value` 타입 확장** — 값 저장소가 `Record<string, ScalarValue>[]` 를 받는다. 스냅샷 복사 · 완결성(「값 자리 입력됨」 = 행 1개 이상) · 식 언어 `exist` 가 이 값을 안다.
- **시스템 폼 편집 규칙** — 마스터 화면([[기능/마스터/마스터]] §3.5 폼 카드)에 잠금 표시와 거부 메시지. 시스템 폼에 관리자가 필드를 더하면 그 필드는 일반 필드 규칙.
- **시드** — 폼 둘(코드 마스터). 투영 구분자는 시드하지 않는다(결정 5, 2026-09-28).
- **B 단계 예약** — 표 열 투영(`폼.필드.열키`) · `max/min` 집계는 값 비교 조건식(B)에서. 이 ADR 은 문법 자리만 예약한다.
