# 담보트리 시나리오

> 상태: 초안 · 최종수정: 2026-09-01
> 관련 기획: [[기능/담보/담보]] · [[00_시작/도메인모델]] §1

## 시나리오 1 — 단순 담보 생성 (일반상해사망)

**전제**: 담보 마스터 목록이 비어 있다.
**흐름**:
1. 담보 마스터 화면에서 새 담보 생성 → 담보명 「일반상해사망」 입력.
2. 최소 구조에 맞춰 세부보장 1개(「일반상해사망」)·급부 1개(「일반상해사망보험금」) 구성.
3. 저장.
**기대 결과**: 담보 > 세부보장 > 급부 3층이 각 1개인 최소 사례로 저장된다.
단순 담보도 층을 생략하지 않는다 ([[00_시작/도메인모델]] §1).
**경계·오류**: 세부보장 0개 또는 급부 0개 상태의 담보는 성립하지 않는다 — 최소 구조 강제.
**강제는 이중이다** (2026-09-01 확정): UI 가 생성 시 최소 1개 이상을 넣도록 강제하고,
서버도 저장 시 하한을 검증한다 — 화면을 우회한 잘못된 요청은 오류 메시지로 거부 (숨김 ≠ 잠금).

## 시나리오 2 — 수술비 담보 구성 (세부보장 7개)

**전제**: 담보 마스터가 있고, 수술비 담보는 아직 없다.
**흐름**:
1. 담보 「수술비」 생성.
2. 세부보장 7개를 순서대로 추가: 1종수술 ~ 7종수술.
3. 각 세부보장에 급부 1개(수술보험금) 추가.
4. 저장.
**기대 결과**:
- 세부보장 7개·급부 각 1개의 트리가 저장된다 — 세부보장 복수 담보의 MVP 실물
  ([[00_시작/도메인모델]] §7 수술비 실물 배치).
- 담보명·세부보장명·급부명은 구분자 값이 아니라 **뼈대 속성**으로 저장된다.
  문면 반복문이 내장 경로(`세부보장.세부보장명`)로 접근할 수 있다.
**경계·오류**: 급부 없는 세부보장(예: 급부 추가 전 저장 시도)은 최소 구조 위반.

## 시나리오 3 — 형제 간 이름 중복 금지

**전제**: 수술비 담보에 세부보장 「1종수술」~「7종수술」이 있다.
**흐름**:
1. 수술비 담보에 세부보장 「1종수술」을 추가 시도 → 거부, 형제 이름 중복 사유 안내.
2. 기존 세부보장 「2종수술」의 이름을 「1종수술」로 변경 시도 → 같은 이유로 거부.
3. 다른 담보(일반상해사망)에 세부보장 「1종수술」 추가 → 허용.
**기대 결과**: 중복 금지는 **형제 간**에만 적용된다 — 다른 부모 아래 동명은 허용.
**경계·오류**: 급부 레벨도 동일 — 한 세부보장 안 급부끼리만 이름 중복 금지.

## 시나리오 4 — 순서는 데이터다 (수록·순회 순서)

**전제**: 수술비 담보(세부보장 1종수술~7종수술)가 있고, 담보약관 문면에
`for 세부보장 in 세부보장목록` 반복문(보장범위 조·지급금액표)이 있다.
**흐름**:
1. 트리 편집 화면에서 세부보장 순서를 재배열 (예: 7종수술을 맨 앞으로).
2. 저장 후 담보약관 문면 미리보기 확인.
**기대 결과**: 반복문 출력 순서·문면 수록 순서가 트리의 형제 순서를 그대로 따른다
(7종수술이 첫 행) — 순서는 표시용이 아니라 데이터다.
**경계·오류**: 순서를 별도로 지정하는 다른 입력 경로는 없다 — 트리가 유일한 출처.

## 시나리오 5 — 트리 하한 삭제 거부

**전제**: 일반상해사망 담보(세부보장 1·급부 1)가 있다.
**흐름**:
1. 유일한 급부 삭제 시도 → 거부 (세부보장은 급부 1개 이상).
2. 유일한 세부보장 삭제 시도 → 거부 (담보는 세부보장 1개 이상).
**기대 결과**: 최소 구조를 깨는 삭제는 성립하지 않는다.
**경계·오류**: 수술비처럼 세부보장이 7개면 6개까지는 삭제 가능 — 하한은 1.

## 시나리오 6 — 탑재된 담보의 구조 변경 (모드 분기)

**전제**: 수술비 담보가 어느 상품에 탑재돼 있다(값 스냅샷 존재). 서버는 프로덕션 모드.
**흐름**:
1. 프로덕션 모드에서 세부보장 추가 시도 → **서버가 거부** (화면 숨김이 아니라 거부 —
   [[00_시작/도메인모델]] §5).
2. 개발 모드로 전환 후 세부보장 「8종수술」 추가 → 허용.
3. 개발 모드에서 세부보장 「7종수술」 삭제 → 허용.
**기대 결과**:
- 추가된 노드는 기존 상품담보에 **빈 값(미입력)** 으로 나타난다 — 마스터 기본값의 사후 복사 없음.
- 삭제된 노드의 상품담보 값 행은 함께 삭제된다.
**경계·오류**: 탑재된 상품이 없는 담보의 구조 변경은 프로덕션에서도 허용.
