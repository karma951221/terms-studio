# 동적표

> 상태: 초안 · 최종수정: 2026-10-17

## 1. 한 줄

담보약관에 들어가는 **감액 지급금액 표**(「구 분」 + 감액 구간 열, 셀 「보험가입금액의 n%」)를 급부 종류마다 짜인 로직이 아니라 **정의 객체**로 만든다 — 행 기준 · 열 기준 · 머리글 템플릿 · 셀 템플릿을 정의에 적어 두면, 조립이 그 담보의 급부 · 감액 값으로 표를 펼친다.
작성자가 동적표를 정의하고(함수조항처럼 코드 · 이름 · 인자를 가진 재사용 단위), 담보약관 문면 작성자가 문면에 동적표 참조를 넣어 인자를 연결하며, 상품 미리보기 · 조립이 상품담보 스냅샷으로 표를 찍는다.

## 3. 규칙

### 3.1 정의

- **동적표는 독립 객체다** — 함수조항([[기능/함수조항/함수조항]])과 같은 뼈대: 코드 시스템 발급 · 이름 · **인자** · 본문 대신 **표 규칙**. 메뉴 「동적표」에 목록이 있고, 사용처(담보약관 문면)는 참조만 둔다. 고치면 쓰는 곳 전부에 전파된다. **미구현**
  — 왜: 같은 표 모양(감액 구간 열 · 「보험가입금액의 n%」)이 담보마다 되풀이된다. 문면 노드의 속성으로 두면 담보약관마다 머리글 · 셀 문구를 다시 적는다.
- **인자는 값 인자만** — 함수조항의 `ParamDef{name, type, default}` 를 그대로 쓴다. 조 참조 인자는 없다 ([[기능/담보/결정/ADR-0087-담보노드키-키경로참조-함수조항인자연결]]). **미구현**
- **동적표는 담보속성 · 세목 · 구분자를 직접 읽지 않는다** — 템플릿 안 조건 · 값별 분기는 인자(`arg.X`)만 읽는다. 기준일 낱말(「최초계약일」/「계약일」)은 인자(갱신형 여부)로 받아 템플릿 안 조건이 고른다. **미구현**
  — 왜: 함수조항과 같은 결이다([[기능/함수조항/함수조항]] §3.3) — 값이 어디서 오는지는 사용처가 정하고, 정의는 어느 담보에 들어갈지 모른다.
- **표는 세목 · 담보속성으로 갈리지 않는다** — 행 · 열은 담보 구조(급부)와 급부의 감액 값만으로 정한다. **미구현**
- 정의의 칸 **미구현**:

  | 칸 | 값 | 비고 |
  |---|---|---|
  | 행 기준 | `급부명` (고정 하나) | §3.2 |
  | 열 기준 | `감액 구간` 또는 `없음` | §3.2 |
  | 구분 칸 머리글 | 글, 기본 「구 분」 | |
  | 열 머리글 템플릿 | **첫 열** · **가운데 열** · **마지막 열** 세 벌 + 열 하나일 때 **단일 열** | §3.3 |
  | 셀 템플릿 | 인라인 노드, 기본 「보험가입금액의 {비율}%」 | §3.3 · §3.4 |

### 3.2 행 · 열

- **행 = 급부명** — 급부 하나가 한 행이고, 급부명이 같은 급부는 한 행으로 묶인다(세부보장이 달라도). 행 순서는 담보 트리 순서(세부보장 순 → 급부 순)로 처음 나온 자리다. 묶기 조건은 §3.4. **미구현**
  — 왜: 약관에서 한 줄로 쓰고 싶은 급부는 작성자가 급부명을 같게 적는다 — 따로 보이려면 급부명을 다르게 적는다. 세부보장 칸을 따로 두거나 합치지 않는다.
- **열 = 감액 구간** — 그 담보 모든 급부의 감액 경계(`reduction.periods` 의 `end`)를 합친 집합(오름차순, 같은 개월 수는 하나)으로 나눈다. 경계 k 개면 열 k + 1 개. 열 수에 상한을 두지 않는다. **미구현**
  — 왜: 머리글 템플릿이 첫 · 가운데 · 마지막 세 벌이라 n 열이 저절로 된다 — 상한은 규칙을 하나 더 만들 뿐 막을 이유가 없다.
- **열 기준 「없음」이거나 경계 합집합이 비면 열은 하나** — 머리글은 단일 열 템플릿(기본 「지급금액」)이다. (갱신) 표 · 감액이 하나도 없는 담보가 이 모양이다. **미구현**
- 머리글은 한 줄이다 — 위에 「지급금액」 머리를 따로 두지 않는다. 펼친 뒤 열이 고정이라 colSpan 은 쓰지 않는다. **미구현**
- **면책(`exemption`)은 표에 나오지 않는다** (ADR-0065 §6). **미구현**

### 3.3 머리글 · 셀 템플릿과 인자

- **템플릿은 인라인 노드다** — 글 + 슬롯 + 조건 · 값별 분기(대상 `arg.X`). 문면 · 함수조항의 인라인 노드와 같은 모양이다. **미구현**
- 머리글 슬롯 **미구현**:

  | 슬롯 | 값 | 쓰는 템플릿 |
  |---|---|---|
  | `{경계}` | 이 열의 끝 경계 — `formatPeriod`(「1년」 · 「3개월」). 마지막 열은 끝이 없어 그 열이 시작하는 마지막 경계 | 첫 · 가운데 · 마지막 |
  | `{앞경계}` | 가운데 열의 시작 경계 | 가운데 |

- 열 하나 = 단일 열, 열 둘 = 첫 + 마지막, 열 셋 이상 = 첫 + 가운데(열마다) + 마지막. **미구현**
- 감액 표 정의의 머리글 예(〔기준일〕 = 조건 `arg.갱신형` → 「최초계약일」, 그 밖 「계약일」) **미구현**:

  | 템플릿 | 글 | 「갱신형」 · 경계 {1년} 일 때 |
  |---|---|---|
  | 첫 열 | 〔기준일〕부터 {경계}경과시점 전일 이전 | 최초계약일부터 1년경과시점 전일 이전 |
  | 가운데 열 | 〔기준일〕부터 {앞경계}경과시점 이후 〔기준일〕부터 {경계}경과시점 전일 이전 | — |
  | 마지막 열 | 〔기준일〕부터 {경계}경과시점 이후 | 최초계약일부터 1년경과시점 이후 |
  | 단일 열 | 지급금액 | — |

- **셀 슬롯 `{비율}`** = 그 행 · 그 열의 셀 비율(§3.4, % 수). 기본 셀 템플릿 「보험가입금액의 {비율}%」. **미구현**
- **「해당보장의」 접두는 셀 템플릿 안 조건이다** — 조건은 내장값 `builtin.coverage.subCoverageCount ≥ 2`(가칭 — 그 담보의 세부보장 수). **미구현**
  — 왜: 세부보장 수는 담보 구조라 세목 · 담보속성이 아니다(§3.1 「갈리지 않는다」에 걸리지 않는다). 인자로 받으면 담보마다 사람이 세어 연결해야 한다.
- **담보마다 다른 머리글 꼬리(주요치료비 단서문구 — 「「2대질환」으로 진단확정 시」)는 글 인자 하나다** — 머리글 템플릿 끝에 `{arg.단서}` 를 두고 문면이 그 담보의 글을 연결한다. 별도 장치는 없다. **미구현**
  — 왜: 질환명이 담보마다 달라 시스템이 만들 수 없고, 인자 하나로 된다.

### 3.4 셀 계산과 묶기

- **열 j 의 감액비율** — 열 j 의 구간 [b(j−1), b(j)) 에서 급부 g 의 감액비율 = g 의 `reduction.periods` 중 `end ≥ b(j)` 인 첫 행의 `rate`, 없으면 `after_rate`(기본 100). 감액 폼을 열지 않은 급부는 모든 열 100. 마지막 열(끝 없음)은 `after_rate`. **미구현**
  — 왜: 경계를 합치면 한 급부의 구간이 여러 열로 쪼개진다 — 제 경계가 없는 열도 그 열을 덮는 자기 구간의 비율로 채운다(제 90일 경계가 없는 급부의 첫 열 = 1년 구간 비율).
- **셀 비율 = `pay.rate` × 감액비율 / 100** — 정수가 아니면 소수 한 자리까지 그대로 찍는다. 반올림하지 않는다. **미구현**
  — 왜: 감액 지급률은 급부 지급률에 곱하는 비율이다([[기능/담보/담보]] §3.4). 곱이 없으면 지급률 20% 급부의 감액 50%(→ 10%)를 쓸 수 없다.
- **묶기는 열마다 셀 비율이 모두 같을 때만** — 급부명이 같아도 어느 열에서든 비율이 다르면 묶지 않고 급부마다 따로 행을 찍고, 경고 `dynTableMergeConflict` 를 낸다. 면책만 다른 급부는 묶인다(면책은 표에 없다). **미구현**
  — 왜: 표에 나오는 값이 다른 급부를 한 행으로 찍으면 한쪽 값이 조용히 사라진다. 막지 않고 경고하는 것은 작성자가 급부명을 고치면 풀리는 일이라 조립을 멈출 일이 아니기 때문이다.
- 읽는 창구는 `reductionPeriods(read)`(급부 하나의 감액 구간 — 폼을 안 열었으면 없음) · `pay.rate`. **미구현** (창구 함수는 있다 — 호출처가 없다)

### 3.5 문면 삽입과 (갱신) 표

- **삽입 노드 `dynTableRef{tableCode, bindings}`** — 담보약관 문면의 블록 노드, 조 자리 · 항 아래 목록에 선다([[기능/문면/문면]] §3.2 · §3.6). 편집기 메뉴 「아래에 동적표 추가…」(함수조항 추가 옆). 넣지 않으면 사람이 정적 표로 직접 쓴다. **미구현**
- **인자 연결은 함수조항과 같은 `Binding`** — 상수 · 구분자. 갱신형 여부는 문면이 담보속성 갱신형을 읽는 구분자로 연결한다(동적표는 속성을 모른다 — §3.1). **미구현**
- **문맥은 담보약관(상품담보)** — 급부 집합은 그 상품담보 스냅샷의 담보 트리 전체 급부다. 보통약관 문맥에 넣으면 `structure` 오류다. **미구현**
- **(갱신) 표는 두 번째 정의 + 문면 조건 노드** — 열 기준 「없음」 · 셀 「보험가입금액의 {비율}%」(감액이 없어 비율 = 지급률)인 정의를 따로 두고, 문면이 갱신형 조건 블록 안에 넣는다. 조립에 「항상 생성 · 갱신형만 노출」 같은 특수 규칙을 두지 않는다. **미구현**
  — 왜: 조건 노드로 이미 쓸 수 있는 일을 조립 규칙으로 두면 문면에 보이지 않는 표가 생긴다.

### 3.6 조립 · 검사 · 오류 좌표

- **펼침** — 조립이 `dynTableRef` 를 만나면 급부 열거 → 경계 합집합 → 행 묶기 → 셀 계산 → 머리글 · 셀 템플릿 평가(인자 연결을 바꿔 쓴 뒤 — 함수조항과 같은 자리) → 기존 `RTable` 로 낸다. 렌더는 기존 정적 표 그대로다([[기능/조립산출/조립산출]] §3.1). **미구현**
- **저장 검사(동적표 정의)** — 템플릿이 읽는 `arg.X` 가 선언돼 있음 · 값별 분기 값이 그 열거형에 있음 · 슬롯 이름이 그 템플릿에서 쓸 수 있는 것(§3.3 표) — 어기면 저장 거부. **미구현**
- **삽입 검사(문서 저장)** — 바인딩 누락(`argUnbound`) · 타입 불일치 · 없는 인자에 연결 · 없는 동적표 · 보통약관 문맥 — 함수조항 참조의 문서 저장 검사와 같은 결([[기능/함수조항/함수조항]] §3.4). **미구현**
- **오류 좌표** — 「조 › 동적표 <코드> › 행 <급부명> › 열 n」. 원천은 셀 값이면 그 급부의 감액 · 지급률 값, 템플릿이면 동적표 정의(`/dyntables/<코드>`). **미구현**
- 경고 `dynTableMergeConflict` 는 완성본을 깨지 않는다 — 좌표는 그 행(급부명), 문구에 갈린 열과 두 비율. **미구현**

### 4.2 `/dyntables/<code>` (가칭) — 상세 (L2) · `/dyntables/new` 는 처음부터 편집 중인 같은 화면

| 자리 | 내용 |
|---|---|
| 기본정보 | 코드 · 동적표명 |
| 인자 | 함수조항 인자 표와 같은 모양 — 이름 · 타입 · 기본 연결 |
| 열 기준 | 「감액 구간」 / 「없음」 |
| 머리글 | 구분 칸 머리글(글) · 열 머리글 템플릿 — 첫 열 · 가운데 열 · 마지막 열 · 단일 열 네 줄, 줄마다 인라인 편집기(글 · 슬롯 `{경계}` · `{앞경계}` · 조건 · 값별 분기). 열 기준 「없음」이면 단일 열 한 줄만 |
| 셀 템플릿 | 인라인 편집기(슬롯 `{비율}` · 조건) |
| 미리보기 | 표본 급부로 펼친 표 — 표본 = 급부명 · 지급률 · 감액 구간 몇 줄 + 인자 값. 표본은 저장하지 않는다 |

**상태.**

| 상태 | 화면 |
|---|---|
| 읽기 | 모든 칸 읽기 전용(템플릿은 칩으로 조판). 미리보기는 늘 보인다 |
| 편집 | `편집`을 누르면 칸 전부가 함께 수정 가능해지고 같은 버튼이 `저장`으로 — 칸마다 저장 버튼이 없다 |
| 오류 | 저장 거부면 그 칸(인자 · 템플릿 줄) 아래에 사유와 고칠 곳 — 입력률 · 완결성 표시는 두지 않는다 |
| 빈 미리보기 | 표본 급부가 없으면 「표본 급부를 더하면 표가 펼쳐진다」 |

**유저액션.**

| 누르면 | 결과 |
|---|---|
| `편집` | 기본정보 · 인자 · 열 기준 · 머리글 · 셀 템플릿이 수정 가능, 버튼이 `저장`으로 |
| `저장` | 한 번에 반영 — 검사(§3.6) 통과 시 읽기로, 실패 시 편집 유지 + 오류 자리 |
| 편집 중 경로 링크 | 「저장하지 않은 변경 사항」 확인 |
| 미리보기 표본 줄 더하기 · 빼기 · 인자 값 바꾸기 | 미리보기 표가 다시 펼쳐진다(저장과 무관) |

## 5. 미결

- **체증형 · 이차이벤트 체증형** — 행이 체증 구간 · 연차로 펼쳐지는 표(레퍼런스 케이스 7 ~ 9). 다음 기획.
- **급부 「형태」 필드** — 체증 기획 때 같이 정한다. 지금 두면 읽는 곳이 없다.
- **셀값 확장** — 셀 비율을 지급률 × 감액 밖으로 바꾸는 것. 다음 기획.
- **`builtin.coverage.subCoverageCount` 의 정식 이름** — 가칭이다. 식 언어 내장값 이름 규칙([[공통/기술/식언어]])에 맞춰 구현 때 정한다.
- **일 단위 경계** — 감액 경계는 개월 수라([[기능/담보/담보]] §3.4) 「90일」 경계를 적을 수 없다(인수 케이스 3 — [[QA/인수기준]]). 실물 수요가 생기면 연다.

### 6.1 이 기능의 ADR

### 6.2 결정 메모

| 결정 | 왜 | 버린 안 |
|---|---|---|
| 동적표 = 독립 객체(코드 · 이름 · 인자 · 표 규칙), 문면엔 참조 노드 + 인자 연결 (§3.1 · §3.5, 2026-10-17 사용자 결정) | 같은 표 모양이 담보마다 되풀이된다 — 함수조항처럼 한 곳에서 고치고 전파한다 | 문면 표 노드의 속성으로 표 규칙을 적기 · 급부 종류마다 표 로직 |
| 행 = 급부명(같으면 한 행), 열 = 감액 구간(경계 합집합) (§3.2, 2026-10-17 사용자 결정) | 현행 표가 그렇게 읽힌다. 묶고 싶으면 급부명을 같게 — 작성자가 이미 쥔 손잡이다 | 세부보장 / 급부 2칸 · 세부보장 칸 합치기 · 세목 · 담보속성 축 |
| 기준일 낱말 = 머리글 템플릿 + 인자(갱신형 여부) + 조건 (§3.1 · §3.3, 2026-10-17 사용자 결정) | 동적표가 담보속성을 직접 읽으면 함수조항의 「인자만 읽는다」와 결이 갈리고, 정의가 어느 속성을 읽는지 숨는다 | 동적표가 담보속성 갱신형을 직접 읽기 · 기준일을 시스템 고정 문구로 |
| 열 수 제한 없음 (§3.2) | 머리글 템플릿 세 벌이라 n 열이 저절로 된다 | 최대 3열(현행 요건) |
| 같은 급부명 · 비율 다름 = 경고 `dynTableMergeConflict` + 따로 찍기 (§3.4) | 급부명을 고치면 풀리는 일이라 조립을 멈출 일이 아니다. 값이 사라지지 않게 따로 찍는다 | 조립 오류로 막기 · 첫 급부 값으로 묶기 |
| (갱신) 표 = 두 번째 정의 + 문면 조건 노드 (§3.5) | 조건 노드로 쓸 수 있는 일을 조립 규칙으로 두면 문면에 보이지 않는 표가 생긴다 | 조립의 「항상 생성 · 갱신형만 노출」 특수 규칙 |
| 주요치료비 단서문구 = 글 인자 하나 (§3.3) | 질환명이 담보마다 달라 시스템이 만들 수 없고, 인자 하나로 된다 | 담보 공통변수 같은 별도 장치 |
| 「해당보장의」 = 셀 템플릿 안 조건(내장값 세부보장 수 ≥ 2) (§3.3) | 세부보장 수는 담보 구조라 세목 · 담보속성 축이 아니다. 인자로 받으면 사람이 세어 연결한다 | 인자로 받기 · 시스템 고정 접두 |
| 셀 비율 = 지급률 × 감액비율, 소수는 한 자리까지 그대로 · 반올림 없음 (§3.4, 2026-10-17 사용자 결정 — 셀 공식) | 곱이 없으면 지급률 20% × 감액 50% 를 쓸 수 없다. 반올림 규칙을 정할 실물 근거가 없다 | 감액 지급률을 셀 표시값으로 · 정수 반올림 |
| 체증 · 급부 형태 필드는 이번 범위 밖 (§5) | 형태 필드는 읽는 곳(체증 표)이 생길 때 같이 정해야 모양이 맞는다 | 형태 필드를 먼저 두기 |
