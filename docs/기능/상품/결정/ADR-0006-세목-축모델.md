# ADR-0006 — 세목 축 모델: 축은 유형의 그릇이 아니다

> 상태: 채택 · 날짜: 2026-08-29 (일부 당일 번복 포함)

## 맥락과 경위 (당일 전개)

1. 「세목은 종·형 2축」으로 가정 채택.
2. **같은 날 반례로 폐기** — 기본납입형/가벼운납입형을 한 상품에서 동시 운영하는 사례.
   세목이지만 종·형으로 구분하지 않는다.
3. 「축 = 유형 자리」도 반례 — 형 축에 무저해지유형의 1형(해약환급금지급형)·2형(미지급형)과
   **계약전환형유형의 4형**이 공존한다. 한 축이 여러 유형을 담는다.

## 결정

- 유형을 고르는 단위는 축이 아니라 **종형 번호 하나하나**. 뼈대:
  `(축, 번호, 이름, 세목유형 참조, 유형 구조체 값)`.
- **한 유형은 한 축에만** 걸칠 수 있고(terms-lab 규칙 계승), **여러 유형이 한 축에** 걸칠 수 있다.
- 한 축의 번호들은 배타적 선택지 — 계약은 축마다 하나를 고른다. (2종, 4형)처럼 유형이
  엇갈리는 조합도 의미는 「축마다 하나씩 고른 것」일 뿐.
- **문면 번호는 선택 속성** — 번호 없는 선택지가 존재하고, 같은 유형이라도 종형 축으로
  분리할지는 상품마다 다르다(유형의 성질이 아니라 상품별 결정).
- **조합은 카테시안이 아니다** — 상품에는 명시 등록한 유효 조합만. 제약이 유형을 가로지른다
  (예: 특정 고지유형에서는 기본납입형만 운영).
- **세목유형마다 필드가 다르다 → 유형 하나 = 구조체 하나.** 유형 5종: 납입면제·무저해지·
  계약전환·영위업종적용·납입형태. 고지유형은 세목이 아니라 **상품 레벨 enum 구분자**
  (일반심사·간편심사·건강고지)로 확정.
- MVP 경계: 번호 없는 축 미고려. 종·형 둘 다 / 하나만 / 0종0형 세 경우만.
  보험료가벼운납입형 미고려(판매중지 가능성 + 지엽적) — 단 「번호 없는 선택지」 자리는 모델에 유지.

## 교훈

가정을 「가정」으로 표시해 둔 덕에 당일 반례 수용이 저렴했다. 세목 관련 결정은 반례가
나오는 즉시 뒤집을 수 있게 근거와 함께 적는다.
