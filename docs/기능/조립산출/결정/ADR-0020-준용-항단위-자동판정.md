# ADR-0020 — 준용: 항 단위 리터럴 비교 자동 판정 + 「비교 제외」 옵션

> 상태: 채택 · 날짜: 2026-09-06
>
> 개정 반영: 2026-09-14 (§1) — 원본은 _archive/2026-09-27_문서재편/06_결정/
> 자동 판정 범위를 좁힌 결정([[기능/조립산출/조립산출]] §3.5 준용 · 생략 판정 · §6.2)이 판정 범위를 「검증된 경우(순서 일치)」로 좁히고, 항 순서가 다른 조를 미합의 사례(통째 + warning)로 분류했다.

## 맥락

생략 자동 판정([[기능/조립산출/조립산출]] §3.5 준용 · 생략 판정)은 처음에 「조 단위 완전 동일 → 생략」만 정했다. 실물에는 그 밖의 준용이 있다 —
담보 조가 보통약관 조를 포함하면서 항을 더 갖는 경우(「보통약관 제N조를 준용합니다」 + 추가 항),
보통약관 조가 담보 조를 포함하는 경우(문맥상 보통약관 조로 갈음). 기존 시스템은 이를
3종 옵션(생략·덮어쓰기·준용/생략 예외처리)으로 사람이 선언했고, 우리는 그 대체 규칙이 필요했다.

## 결정

1. **관계는 자동 판정한다.** 조연결만 하면 조립이 **항 단위**로 「조건 해소가 끝난 텍스트」를 리터럴
   비교해 생략 / 준용 / 통째 셋 중 하나로 가른다. 준용이면 제1항에 준용 문장을 자동 생성하고
   보통약관에 없는 항만 뒤에 찍는다.
   생략 · 준용은 **검증된 경우(항 순서 일치)** 에만 내고, 미합의 사례(같은 항 두 번 · 항 순서 변경 · 항 참조 슬롯 · 참조 · 표를 품은 항)는
   통째 + 검토 사유 warning 이다 — 조건표 · 미합의 사례는 [[기능/조립산출/조립산출]] §3.5 준용 · 생략 판정.
2. **보통약관 조 옵션은 「비교 제외」 하나뿐이다.** 보통약관 조 안의 **block 공용조항 참조 노드**에
   붙고, 켜면 그 항을 뺀 나머지로 판정한다. inline 참조에는 두지 않는다.
3. 기존 3종 옵션은 만들지 않는다 — 생략·준용은 1로, 덮어쓰기는 [[기능/조립산출/결정/ADR-0021-기본계약수-보통약관구조]]
   의 「조연결 = 대치」로, 예외처리는 2로 흡수된다.

## 이유

- **명시 선언(유형 선택)이 더 정확하지만 시스템으로 지킬 수 없다** — 내용이 바뀌어도 선언이 남아
  거짓말한다 (수동 생략 플래그를 버린 것과 같은 이유). 자동 판정은 탑재분별로 정확하다.
- 항 단위여야 「포함」을 판정할 수 있다. 조 단위 비교로는 생략/통째 둘뿐이다.
- 비교 대상은 공용조항 id 나 조건식이 아니라 **결과 텍스트**다 — 다른 경로로 같은 문장이 나오면
  같은 것이고, 같은 공용조항이라도 옵션·값이 달라 문장이 다르면 다른 것이다.

## 버린 대안

- **A. 조연결에 관계 유형(생략 후보 / 준용)을 명시 선언** — 정확하나 선언이 내용과 어긋나도 아무도
  모른다. 기각.
- **B. 비교 제외를 inline 참조에도 허용** — 항 텍스트 일부를 오려내 비교하는 규칙이 하나 더 필요하고
  판정이 불투명해진다. 실물 요구 없음. 기각.
- **C. 비교 제외를 조 단위 옵션으로** (1차 기획의 「적용 단위 = 조 전체」) — 조 전체를 빼면 판정할
  것이 없다. 실제 필요는 「이 항은 빼고 비교」다. 기각.
- **D. 항 순서 무관 매칭** (이 ADR 이 처음 열어 둔 상태) — 실물 반례가 없다는 이유로 넓게 열었으나,
  순서가 다르면 항 번호가 달라져 다른 곳의 항 참조가 어긋난다. 반례 없음이 안전의 근거는 아니다 — 미합의 사례로 내렸다([[기능/조립산출/조립산출]] §3.5).

## 결과와 감수하는 비용

- 조립 파이프라인의 생략 단계가 판정기 + 준용 문장 생성기로 커진다 (아키텍처 갱신).
- 준용 문장·조사(은/는)·조 번호가 계산값이 되어 문면 작성자가 손댈 수 없다 — 문장 변형이 필요한
  실물이 나오면 템플릿 확장으로 대응한다.
- 자동 생략이 줄어든다 — 순서만 다른 조는 통째로 찍히고 warning 이 뜬다. 작성자가 순서를 맞추면 자동 판정 안으로 들어온다.
