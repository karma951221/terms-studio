`_structure.json`의 내용:

- `units`: 단위별 쪽 범위
- `toc`: 인쇄 목차 행. `printed`는 인쇄 쪽, `pdf`는 PDF 쪽이다
- `headings`: 추출한 제목 전부. 파일·종류(group/절/특약/관/조/별표)·수준·PDF 쪽을 담는다

## 3. Markdown 표기 규칙

| 원문 | md |
|---|---|
| 대분류 · 절 · 특약 · 관 · 조 · 별표 | 파일 안에서 계층대로 `#` 수준을 붙인다. 파일 제목이 `#`이다. 예: 주계약 특약 파일은 `## 특약` › `### 조` |
| 항 번호 (원본은 네모 숫자. 글꼴의 사설 영역 글자 U+F000이라 숫자가 사라진다) | 조마다 순번을 다시 매겨 `[1]` `[2]` …로 쓴다. 세부보장 패널 안의 작은 조 `**1.(보험금의 지급사유)**`에서도 다시 센다 |
| 호 ①② · 목 가. 나. / 가) 나) · 세목 1) 2) | 원문 기호 그대로 쓴다. 줄 머리 `1.`은 자동 번호 목록이 되지 않게 `1\.`로 쓴다 |
| 테두리 상자 (【용어풀이】 · 법령 인용 · 【예시】 상자) | `>` 인용구 |
| 표 | 마크다운 표. 안쪽 가로줄 없이 뭉친 행은 값 열(코드 · 지급률처럼 숫자가 든 짧은 줄)의 줄 위치로 다시 나눈다 |
| 쪽 · 단을 넘어 이어지는 표 | 바로 앞 표와 열 수가 같으면 한 표로 붙인다. 반복 머리글은 버린다 |
| 6~8pt 예시 그림 (타임라인 · 화살표 · 도식) | `[그림 — 원문 PDF p.N]`. 그림 위 설명 문장(`- …`, `※ …`)과 그림 안 표는 남긴다 |
| 쪽 경계 | `<!-- p.N -->` (PDF 쪽) |
| 회색 음영 패널 (세부보장 블록) | 음영 없이 본문으로 쓴다 |

### 4.1 목차 대조 (`verify_structure.py`) — 누락 0

목차와 본문의 표기가 다른 곳은 대조 전에 정규화한다.

- 공백과 가운뎃점 변종(ㆍ · ･ ・)을 지운다. 예: 「유괴인신매매」와 「유괴･인신매매」
- 무번호 `【별표】`는 목차에 제목이 없어 라벨만 비교한다.

## 5. 알려진 한계

- **항 번호는 다시 센 값이다.** 원본 네모 숫자는 글자로 추출되지 않는다.
  항 문단이 줄 첫머리의 U+F000으로만 인식되므로, 그 글자가 없는 항(쪽 경계에서 끊긴 항 등)은 앞 항에 붙는다.
  재현 대조 때는 본문의 「제N항」 참조와 순번이 맞는지 함께 본다.
- **예시 그림은 내용이 없다.** `[그림 — 원문 PDF p.N]` 자리에서 원본 쪽을 본다.
  9pt 본문 크기로 찍힌 그림 글자는 그림으로 판정되지 않아 조각으로 남는다. 예:
  - p.536 「A B D … 30 31 32」
  - p.623 「승인한 요법」이 아닌 경우」
  - p.1537 마지막 도식 설명 줄
  그림 판정에 들어가는 문턱은 8.6pt다(본문 9pt). 그림 수는 338자리다.
- **표 서식이 단순해진다.** 병합 셀 · 음영 · 열 너비가 없다. 병합 셀의 라벨은 묶음의 첫 행에만 쓰고 나머지 행은 빈칸이다.
  여러 줄 라벨은 띄어쓰기 없이 붙는다(「특정 소액암」 → 「특정소액암」).
- **이어 붙인 표는 쪽 표시를 잃는다.** md 표 가운데에 주석을 넣을 수 없어서다.
  표 바로 뒤에 열 수가 같은 다른 표가 오면, 원문에서 다른 표라도 한 표로 붙는다.
- **음영 패널의 경계가 없다.** 세부보장 블록(회색 배경 · 파란 글씨)이 어디서 시작하고 끝나는지는 md에 남지 않는다.
  안쪽 「1.(…)」 제목으로만 알 수 있다.
- **원문 줄 끝 공백에 기대는 띄어쓰기.** 줄을 이을 때 앞 줄 끝에 공백이 있으면 띄우고, 없으면 붙인다.
  원문 조판이 줄 끝 공백을 빼먹은 곳은 단어가 붙는다(예: 「그 정도③」).
  상자 안 번호 목록은 「1.전자문서에」처럼 번호 뒤 공백이 빠지기도 한다.
